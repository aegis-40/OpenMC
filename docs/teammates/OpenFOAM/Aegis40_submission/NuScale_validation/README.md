# NuScale-Class Conjugate Fuel-Pin CFD — Verification & Validation

> Validation companion of the Aegis-40 thermal-hydraulic analysis (parent folder):
> the identical toolchain, proven against the published NuScale NPM-160 point first.

OpenFOAM `chtMultiRegionFoam` conjugate heat-transfer model of a **NuScale NPM-160**
fuel pin (fuel / cladding / coolant), coupled to a correlation-based safety
post-processor (MDNBR, PCT). This is the **validation case** for a small-modular-
reactor design competition: it reproduces the published NuScale operating point to
prove the thermal-hydraulics toolchain is correct *before* it is applied to the
competition reactor geometry.

## Key results (production/medium mesh, NuScale peaking F_q = 1.923)

- **Energy-conservative** — advected power = source to ×1.00 on every mesh (GATE-1).
- **Mesh-independent** — ASME V&V-20 GCI < 0.1 % on outlet & clad temperatures.
- Outlet T 604 K (331 °C ≈ Tsat); peak clad 387 °C single-phase / **352 °C** with
  subcooled boiling; peak fuel 838 °C.
- **MDNBR = 1.977** (> 1.3, +52 %) and **PCT = 352 °C** (≪ 1200 °C) — both pass.
- Reproduces the published NuScale hot-leg temperature, the saturation-boundary hot
  channel and the peak clad temperature **with no tuning**.

Full write-up → [`docs/NuScale_validation_report.docx`](docs/NuScale_validation_report.docx).

Each is a standard OpenFOAM multi-region case:

```
pin_clean/
├── 0.orig/             initial & boundary fields per region (fuel/clad/coolant)
├── system/             solver control
│   ├── controlDict       run control + function objects (bulkTout, massFlow)
│   ├── fvSchemes,fvSolution
│   ├── blockMeshDict     PARAMETRIC butterfly O-grid (mesh knobs n*, g*)
│   └── fuel/ clad/ coolant/   per-region fvSchemes / fvSolution
├── constant/
│   ├── regionProperties        lists the fluid/solid regions
│   ├── g                       gravity
│   ├── fuel/fvOptions          chopped-cosine heat source (scalarCodedSource) ★
│   ├── fuel|clad|coolant/thermophysicalProperties
│   └── coolant/turbulenceProperties   (k-ω SST)
├── Allmesh             blockMesh -> splitMeshRegions -> seed 0/ from 0.orig
└── Allrun              Allmesh -> chtMultiRegionFoam
```
★ `fuel/fvOptions` holds `qpeak` (NuScale-calibrated 2.99e8 W/m³, F_q 1.923) and the
GATE-1 energy-balance note. All three cases carry a byte-identical `fvOptions`.

> **Generated data is not committed** (`0/`, time dirs `3…15`, `constant/*/polyMesh`,
> `dynamicCode/`, `postProcessing/`, logs) — it is reproducible with `./Allrun`. The
> validated results live in the figures, the report, and the post-processors below.

## Reproducing the results

**1 — Run a CFD case.** OpenFOAM v2412 in Docker, **non-root** (the `scalarCodedSource`
heat source compiles C++ at runtime and will not run as root):

```bash
docker run --rm --platform linux/amd64 \
  --user $(id -u):$(id -g) -e HOME=/tmp \
  -v $(pwd):/home/ofuser/OpenFOAM/NuScale \
  opencfd/openfoam-default:2412 \
  bash -c "source /usr/lib/openfoam/openfoam2412/etc/bashrc && \
           cd /home/ofuser/OpenFOAM/NuScale/pin_clean && ./Allrun"
```

**2 — Post-process (host python3):**
```bash
P="--p 12.8 --Tin 531 --G 684 --cp 5250 --L 2.0 --Dco 9.5e-3 --Dh 11.77e-3 \
   --Aflow 87.9e-6 --qpeak 15750 --Fz 1.355 --Le 1.2"
python3 tools/meshindep.py                 # GCI / mesh-independence table
python3 tools/mdnbr.py        $P --table    # MDNBR (W-3 + Tong)
python3 tools/thermal_stack.py $P --boiling  # PCT (with subcooled boiling)
python3 tools/make_figs.py                 # figures F1–F7
pvbatch  tools/make_paraview_figs.py       # figures F8a–c (ParaView >= 5.10)
python3 tools/build_report_nuscale.py      # the .docx report
```

## Method in one sentence
The conjugate CFD provides the energy-conservative flow field, axial heat flux q″(z)
and coolant bulk T(z); the correlation stack (the COBRA/VIPRE/CTF industry standard)
turns those into MDNBR and PCT — used because it carries the CHF and subcooled-boiling
physics a single-phase CFD cannot, **not** because the CFD is inaccurate (its near-wall
heat transfer matches Dittus-Boelter to ~1 %).
