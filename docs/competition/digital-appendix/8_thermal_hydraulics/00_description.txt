================================================================================
 AEGIS-40 DIGITAL APPENDIX — THERMAL-HYDRAULIC ANALYSIS PACKAGE
 (contribution: reactor thermal hydraulics, CFD and safety post-processing)
================================================================================

This package is the thermal-hydraulic part of the Aegis-40 Digital Appendix.
It is self-contained and is merged with the other discipline packages
(neutronics, power-conversion cycle, PRA/I&C, waste & safeguards) into the
team appendix.

Per the appendix rules, for each code it provides: a sample input, a
description of the conditions the input was created for and the approaches
used, the results obtained, and reproducibility / benchmarking / repeatability
evidence with reliable sources (IAEA, OECD/NEA, US NRC, consensus standards)
identified in 04_VV_and_benchmarking/.

--------------------------------------------------------------------------------
 CONTENTS
--------------------------------------------------------------------------------
01_OpenFOAM_CFD/
    Conjugate heat-transfer CFD (OpenFOAM v2412, chtMultiRegionFoam).
    sample_case/ = the production (medium-mesh) 3-region fuel-pin case,
    complete and runnable (mesh regenerated by ./Allmesh; the COLR-envelope
    heat source in constant/fuel/fvOptions). With:
      case_description.txt            conditions / approaches / results
      mesh_independence_summary.csv   ASME V&V-20 grid-convergence (GCI)
      energy_balance_verification.txt GATE-1 energy-conservation check

02_Python_safety_toolchain/
    The complete safety post-processing toolchain (pure python3): natural
    circulation, MDNBR (W-3 / Bowring / Groeneveld LUT), thermal stack (PCT,
    fuel centreline), AOO envelope, cycle MDNBR (BOC/MOC/EOC + COLR envelope),
    flow stability, PRHR grace period, loop-loss budget, mesh-independence,
    figures and report builder. A bare run of each script reproduces the FER
    design point. See README_scripts.txt and requirements.txt.

03_Safety_criteria/
    safety_criteria.yaml — the thermal-hydraulic acceptance criteria used in
    the analyses (MDNBR, PCT, fuel centreline, stability, decay-heat grace),
    with results.

04_VV_and_benchmarking/
    VV_matrix.md                verification & validation matrix (13 items)
    benchmark_sources_list.md   sources, reliability-ranked (IAEA / NRC / STD)
    reproducibility_steps.md    step-by-step reproduction of every FER number
    checksums.txt               SHA-256 of every file in this package

--------------------------------------------------------------------------------
 CODES USED IN THIS PACKAGE
--------------------------------------------------------------------------------
 OpenFOAM v2412 (chtMultiRegionFoam)  conjugate fuel-pin CFD (fuel/clad/coolant)
 Python 3 toolchain (included)        correlation-stack safety post-processing
 ParaView >= 5.10 (pvbatch)           CFD field rendering (figures F9a-c)

 Interfaces to the other packages: pin-power peaking and the COLR envelope are
 taken from the neutronics package (OpenMC record); the steam-generator duty
 (125 MWth, 308/258 C at 12.8 MPa) feeds the power-conversion package.
