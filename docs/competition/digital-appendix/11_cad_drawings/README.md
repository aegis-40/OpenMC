# Digital Appendix — Technical Drawings (CAD)

Engineering technical drawings for the Aegis-40 reactor module and fuel assembly, exported
from the parametric 3-D CAD model. These are the drawing deliverables that accompany the
report's mechanical/geometry basis (Section 8.1.9, Table 8.1-9 and Appendix Table F-1 — the
CAD-controlled dimension register).

## Contents

| File | Sheet | Shows | Report figure |
|---|---|---|---|
| `Aegis-40_A0.pdf` | A0 | Integral reactor-module general-arrangement / assembly drawing (RPV envelope, core, riser, integral OTSG, self-pressurizer/ICRDM upper package, support skirt) with overall dimensions and elevation/nozzle callouts | **Figure 8.1-2** (full reactor assembly drawing) |
| `Aegis-40_A4.pdf` | A4 | Print-size version of the reactor-module assembly drawing above | Figure 8.1-2 (print copy) |
| `FuelAssembly_A4.pdf` | A4 | 17×17 fuel-assembly cross-section — fuel pins, guide/instrument tubes, Gd/Er absorber pins, pin pitch and assembly-envelope dimensions | **Figure 8.2-2a** (fuel-assembly drawing) |

Dimensions on the drawings are consistent with the CAD-controlled register (Appendix Table F-1):
RPV inside/outside Ø 2700–3046 / 3030–3377 mm, total body height 11.16 m, core active height
2000 mm, 37-FA core envelope 1510.82 mm, 17×17 lattice pin pitch 12.623 mm, assembly pitch
216.038 mm.

## 3-D models (provided separately)

The native 3-D CAD (SolidWorks part/assembly files) and neutral **STEP** exports are **not**
included in this compressed appendix because of file size. They are provided on the team's
shared drive:

spatial-coordination source model (Section 8.10.5 reference drawings AE-40-GA-001…006).
