## 2. ⚠️ Unresolved discrepancy — two runs, same quantities, different numbers

**This is the most important finding of the audit and needs a decision.** The same quantities were computed twice, at different statistics, and the deck/FER use the *lower*-statistics values.

| Quantity | STAT_FINAL (Jul 3, 400×50k) | Safety module (Jun 27, 180×20k) | Deck/FER uses |
|---|---|---|---|
| Control-rod bank worth | **21,479 pcm** | 21,509 pcm | 21,509 |
| Hot shutdown margin | **7.68 %** | 7.85 % | 7.85 % |
| k_eff ARI (hot) | **0.92248** | 0.92725 | — |
| Central rod worth | **722.5 pcm** | 844 ± 82 pcm *(Aug 20 REA)* | paper uses 844 |

The bank-worth difference (30 pcm) is inside Monte-Carlo noise and doesn't matter. **The other three do:**

- **Hot SDM 7.68 vs 7.85 %** — both pass the ≥1 % criterion comfortably, so no PASS/FAIL changes, but two documents quoting different numbers is a jury question.
- **Central rod worth 722.5 vs 844 pcm** — this is the **rod-ejection paper's central number**. 722.5 pcm = **1.11 $**; 844 pcm = **1.30 $** (β_eff 650 pcm). Both exceed 1 $, so the paper's conclusion survives either way — but the paper currently cites the *lower-statistics* figure. **The STAT_FINAL value has ~7× the histories and should be preferred**, or both reported with the discrepancy explained.

**DECIDED 2026-08-21 (Samira): the 3 July STAT_FINAL run is authoritative.** Propagated to:

- ✅ Deck `Aegis40-draft-new.pptx` — 5 paragraphs (slides 13, 20, 21, 22, 37)
- ✅ Appendix `README.md`, `1_core_transport/README.md`, `neutronics-STATFINAL-results.md` (the last was mislabelled: it claimed to be the 3 Jul record but its rod-worth/SDM rows carried safety-module values) — checksums refreshed, 218/218 verify
- ✅ Paper draft — both models now reported, production value primary
- ⬜ **FER** — added to `02_FER-DOCX-EDITS.md` for the manual Word pass

### Follow-on finding: the two models differ on absolute reactivity

The gap is **not statistical**. k(ARO) is 1.15042 in the production run and 1.15826 in the safety-neutronics
model — about **590 pcm apart, roughly 10σ**. Both apply the same 10 cm Gd axial cutback.

- Reactivity **differences** are robust: bank worth agrees to 30 pcm (21,479 vs 21,509).
- **Absolute** quantities carry the offset: hot SDM 7.68 % vs 7.85 %, central rod worth 722.5 vs 844 pcm.

Cause not yet identified. **This is now the top open neutronics item** — it does not change any PASS/FAIL,
but two models of the same core should not disagree by 590 pcm, and a reviewer or juror may ask.

## 9. UPDATE 2026-08-22 — the 590 pcm gap is explained, and it is a bug

Chasing β_eff resolved the open item from §2.

### The cause: fuel temperature

The safety-neutronics module defines `T_FUEL_K = 900.0` and then never uses it. Every helper that
builds a state passes `fuel_temp=float(T)` where `T` is the **moderator** temperature — lines 950,
983, 1027, 1057, 1099 of `aegis40_safety_neutronics.py`, covering N5, N5B, N5C, N12 and N12B.

So every hot state in that module ran with fuel at 556 K instead of 900 K. That removes 344 K of
Doppler, worth ≈ 657 pcm at DTC −1.911 pcm/K — the observed gap was 589 pcm. Confirmed directly:
a run at `T_fuel = 900` gave k(ARO) = **1.150421**, matching the production run's 1.1504212 to six
decimal places.

**Not a model difference. A fuel-temperature error.**

| Affected | Not affected |
|---|---|
| Bank worth, k_ARI, hot SDM, ejected-rod worth, the HFP start of the MSLB cooldown | Cold states — fuel and coolant genuinely equilibrate at shutdown, so `k_stuck_cold = 1.031` and the **785 ppm EBIS requirement stand** |

### β_eff computed, not assumed

Prompt-k method, STAT_FINAL both runs, BOC/HFP/ARO:
k = 1.150421 ± 0.000239, k_p = 1.142316 ± 0.000222 → **β_eff = 704.5 ± 28.2 pcm**.
That is ~8 % above the 650 pcm literature default previously used.

### Ejected-rod worth, resolved

| Value | Absorber | T_fuel | Status |
|---|---|---|---|
| **902.2 ± 34.0 pcm = 1.28 ± 0.07 $** | 90 % B-10 | 900 K | **correct for the design** |
| 794 ± 48 pcm | natural B₄C | 900 K | sensitivity |
| 844 ± 82 pcm | 90 % B-10 | 556 K | superseded (fuel-temp error) |
| 722.5 pcm | — | 900 K | production notebook diagnostic |

The production diagnostic's 722.5 pcm sits 1.5σ from the **natural-boron** result and 5σ from the
90 %-enriched one, so that notebook line was evaluated with **unenriched absorber** and does not
describe the final design. It should not be used for the ejected-rod case.

### Consequence for the §2 decision

The "3 July is authoritative" call stands for the **core states** — that run alone used the correct
fuel temperature. It does **not** extend to the `central_rod_worth_pcm` diagnostic, which is for a
different absorber. Use 902.2 ± 34.0 pcm.

## 10. CORRECTION 2026-08-22 (later) — §9 overstated it: convention, not bug

§9 called the fuel-temperature handling a bug. On closer inspection it is a deliberate and defensible
**isothermal hot-zero-power convention**, and the "fix" proposed there would have introduced an error.

The safety-neutronics helpers pass `fuel_temp = float(T)` for **both** the rodded and unrodded state,
so each calculation is internally consistent — an HZP evaluation. Verified: the Doppler shift between
556 K and 900 K appears equally on both states (589 pcm on ARO, 647 pcm on the single-rod case).

**Which basis belongs to which quantity**

| Quantity | Correct basis | Value |
|---|---|---|
| k at BOL, MTC, DTC, void, burnup, cycle length | full power (3 Jul run) | unchanged |
| Rod bank worth, hot shutdown margin | **isothermal HZP** | **21,509 pcm / 7.85 %** |
| Ejected-rod worth | SRP 15.4.8 wants both | 844 ± 82 pcm (HZP) = 1.20 $ · 902 ± 34 pcm (hot fuel) = 1.28 $ |

With rods inserted the reactor is shut down, so a state with rods in *and* fuel at 900 K is not a
physical steady condition. The HZP values are therefore the defensible ones for shutdown reporting.

**Reverted 2026-08-22:** deck (5 paragraphs), appendix (3 files + checksums, 218/218 verify), paper
(§3.1 now reports both bases, Table 1 caption, §6.3 limitation rewritten as an evaluation-state note).
The FER needs **no** change — its existing 7.85 % was right, and the 21 Aug Word-edit request has been
withdrawn in `02_FER-DOCX-EDITS.md`.

**Ladder re-run: not required** (decided 2026-08-22). The HZP ladder is already a consistent
three-configuration comparison, which is the right basis for a shutdown-margin study.
